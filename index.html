Справка — Tibetan CAT Studio Pro

1. Загрузка и меню

  • Открыть TXT — файл с тибетским текстом (одна строка = один сегмент).
  • Проект ▾ (наведение) — сохранить / загрузить проект (.tcat).
  • Словарь ▾ (наведение) — сохранить / загрузить словарь, редактор, скачать словари.
  • Экспорт перевода, Справка — отдельные кнопки.

2. Перевод сегментов

  • Кликните в поле под оригиналом и введите перевод.
  • Ctrl + Enter — зафиксировать перевод (зелёный) или снять фиксацию повторным нажатием.
  • Enter — новый абзац с красной строкой и отступом между абзацами.
  • Форматирование (единый набор для перевода, заметки, пояснения, правки «Проект книги»): при фокусе в поле — панель над ним: B I U, ▮ жёлтый / красный / зелёный фон, •≡ и 1. списки, Tx снять формат. Без всплывающих панелей поверх текста.
  • Карточки с источником Проект книги — кнопка ✎ для правки текста с той же панелью.
  • Номер слева: 3-47 = 3-й сегмент из 47.
  • Кнопка «Заметка» — полупрозрачная; зелёная точка = заметка есть. В заметке: жирный/курсив/подчёркивание, жёлтый/красный/зелёный фон, списки.
  • Кнопка «Редактировать» — правка тибетского текста; «Готово» сохраняет, «Отменить» возвращает текст как было.
  • Иконка закладки под «Редактировать» — пометить сегмент; счётчик Закладки в шапке — список и переход.
  • Кнопка + строка — новая строка в режиме правки (поля раскрыты). Готово сохраняет; если оба поля пусты — строка не создаётся. Отменить — отмена создания.
  • Удалить строку (слева от «+ строка») — удаление сегмента с подтверждением.
  • Номер сегмента: 3-100 — текущий номер и общее число (полупрозрачно).
  • В шапке: Не перев., Готово, Заметки, Закладки — список с переводом, заметкой и метками (Готово / Заметка / Закладка). Жёлтое выделение тоже видно. Esc закрывает.
  • Пока идёт «Редактировать» тибетский текст, окно «пояснение к слову» не открывается.

3. Глоссарий (привязка терминов)

  • Выделите мышью слово или фразу в оригинале.
  • Во всплывающем окне введите пояснение (с форматированием: B/I/U, жёлтый/красный/зелёный фон, списки) → «Привязать к слову» или Ctrl + Enter.
  • Термин подсветится жёлтым; клик по нему прокрутит карточку в правой панели.
  • Справа от каждой строки перевода — источник. У подгруженных словарей: имя (N), где N — число определений в файле словаря.
  • Если участок покрыт несколькими терминами (целое слово и его часть), над предложением появляются ссылки 1 термин, 2 термин… — цифры не вставляются в текст. Клик открывает карточку.
  • Удаление: наведите на строку → × (карточка не прыгает).

4. Словари

  • Загрузить словарь — можно выбрать несколько файлов .tdict сразу. Дубликаты пропускаются. Число на метке = определения в файле. Редактор одного словаря: dict_editor.html.
  • Подсветка (вариант B): точное совпадение строки — རོགས་པ найдётся и внутри རོགས་པའི. При наложении терминов над сегментом — номера 1, 2… Текст не рвётся (гласные/подписные не отрываются от букв).
  • Сохранить словарь — только записи «Проект книги». Подгруженные словари не включаются.
  • Бейдж Словари: N — при наведении список; клик — управление: галочки (вкл/выкл) и «Удалить».
  • Скачать словари — кнопка в группе словарей (ссылку можно задать в коде).

5. Сохранение и экспорт

  • Сохранить проект (.tcat) — сегменты (включая заметки), глоссарий, список словарей.
  • Экспорт перевода — HTML-страница: копировать тибетский / перевод / всё, выделить строки.
  • Имена файлов с датой и временем: 2026-10-20_15-30-00_project.tcat.
  • При закрытии вкладки браузер напомнит сохранить сессию.
  • Каждые 10 минут появляется напоминание «Сохранить проект» (можно отложить «Позже»).

6. Навигация и интерфейс

  • Плавающая кнопка №..? слева внизу — быстрый переход к сегменту по номеру (поле + OK или Enter).
  • Счётчики в шапке: Не перев. / Готово / Заметки / Закладки — клик открывает список и переход к сегменту.
  • На узком экране кнопки меню сжимаются (короткие подписи / иконки), подсказка — при наведении.
  • Тяните вертикальную полосу между панелями, чтобы менять ширину.
  • Esc — закрыть списки счётчиков, поповер, заметку, справку, переход по номеру.
  • Списки счётчиков по ширине совпадают с левой панелью (~70%); форматирование текста в списках сохраняется.

Форматы файлов

  • .txt — исходный текст (UTF-8, по строкам).
  • .tcat — проект (JSON: segments + notes + glossary + loadedDictNames).
  • .tdict — словарь (JSON: {"слово": ["описание1", "описание2"]}).
