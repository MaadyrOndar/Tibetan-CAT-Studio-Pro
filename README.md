# Tibetan CAT Studio Pro v3

Лёгкая браузерная CAT-система (Computer-Assisted Translation), созданная специально для перевода тибетских текстов. Работает локально прямо в браузере без установки сложных программ и серверов.

В репозиторий уже включены демонстрационные файлы для быстрого старта: пример словаря, пример рабочего проекта и полный построчный тибетский текст **«Ламрим Сершунма»**.

## Состав репозитория

* `index.html` — основное приложение **Tibetan CAT Studio Pro v3**.
* `dict_editor.html` — автономный редактор для создания и правки пользовательских словарей (`.tdict`).
* `Lamrim.txt` — полный тибетский текст **«Ламрим Сершунма»**, разбитый построчно для загрузки в программу.
* `2026-11-02_16-38-26_dictionary.tdict` — пример готового пользовательского словаря.
* `2026-11-08_15-27-22_project.tcat` — пример сохранённого проекта с переводом, заметками и привязанным глоссарием.

## Основные возможности

* **Посегментный перевод:** загрузка тибетских текстов из `.txt` (одна строка — один сегмент), удобное редактирование оригинала и перевода, добавление и удаление строк.
* **Умная подсветка терминов:** точный поиск слов и фраз даже внутри сложных конструкций без разрыва тибетской графики (огласовки и подписные буквы не отрываются от коренных).
* **Собственный глоссарий:** выделение фрагментов в оригинале и привязка пояснений с сохранением в проект.
* **Работа со словарями (`.tdict`):** одновременная загрузка нескольких словарей, управление их активностью, встроенный редактор `dict_editor.html`.
* **Форматирование текста:** единая панель для перевода, заметок и глоссария (жирный, курсив, подчёркивание, цветной фон, списки).
* **Навигация и контроль:** быстрый переход к нужному сегменту (`№..?`), закладки, фильтры по статусам («Не переведено», «Готово», «Заметки», «Закладки»).
* **Защита от потери данных:** автоматическое напоминание о сохранении каждые 10 минут и предупреждение при закрытии вкладки.
* **Экспорт:** выгрузка готового перевода в аккуратную HTML-страницу с удобным копированием.

## Быстрый старт

1. Скачайте репозиторий (кнопка **Code → Download ZIP**) или склонируйте его:
   ```bash
   git clone https://github.com
   ```
2. Откройте файл `index.html` двойным кликом в любом современном браузере (Chrome, Firefox, Edge, Safari).
3. **Для знакомства с программой:**
   * Нажмите **«Проект ▾ → Загрузить проект»** и выберите `2026-11-08_15-27-22_project.tcat`.
   * Нажмите **«Словарь ▾ → Загрузить словарь»** и подгрузите `2026-11-02_16-38-26_dictionary.tdict`.
4. **Для начала нового перевода:** нажмите **«Открыть TXT»** и выберите файл `Lamrim.txt` (или любой свой текст в кодировке UTF-8).

## Горячие клавиши

* `Ctrl + Enter` — зафиксировать перевод (или снять фиксацию) / сохранить термин в глоссарий.
* `Enter` — создать новый абзац с красной строкой внутри сегмента.
* `Esc` — закрыть всплывающие окна, списки счётчиков, справку или окно перехода.

## Форматы файлов

| Расширение | Назначение | Структура |
| :--- | :--- | :--- |
| `.txt` | Исходный текст | Обычный текстовый файл в кодировке UTF-8 (разделение на сегменты по строкам). |
| `.tcat` | Файл проекта | JSON-структура, хранящая сегменты, перевод, заметки, глоссарий и список словарей. |
| `.tdict` | Файл словаря | JSON-словарь формата `{"тибетское_слово": ["описание 1", "описание 2"]}`. |
