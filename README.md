# Tibetan CAT Studio Pro v3

Лёгкая браузерная CAT-система (Computer-Assisted Translation), созданная специально для перевода тибетских текстов. Работает локально без установки сложных программ и серверов.

## Основные возможности

* **Посегментный перевод:** загрузка тибетских текстов из `.txt` (одна строка — один сегмент), удобное редактирование оригинала и перевода, добавление и удаление строк.
* **Умная подсветка терминов:** точный поиск слов и фраз даже внутри сложных конструкций без разрыва тибетской графики (огласовки и подписные буквы не отрываются от коренных).
* **Собственный глоссарий:** выделение фрагментов в оригинале и привязка пояснений с сохранением в проект.
* **Работа со словарями (`.tdict`):** одновременная загрузка нескольких словарей, управление их активностью, встроенный редактор словарей (`dict_editor.html`).
* **Форматирование текста:** единая панель для перевода, заметок и глоссария (жирный, курсив, подчёркивание, цветной фон, списки).
* **Навигация и контроль:** быстрый переход к нужному сегменту (`№..?`), закладки, фильтры по статусам («Не переведено», «Готово», «Заметки», «Закладки»).
* **Защита от потери данных:** автоматическое напоминание о сохранении каждые 10 минут и предупреждение при закрытии вкладки.
* **Экспорт:** выгрузка готового перевода в аккуратную HTML-страницу с удобным копированием.

## Быстрый старт

1. Скачайте репозиторий или склонируйте его:
   ```bash
   git clone https://github.com
   ```
2. Откройте главный HTML-файл проекта в любом современном браузере (Chrome, Firefox, Edge, Safari).
3. Нажмите **«Открыть TXT»**, чтобы загрузить тибетский текст, или **«Проект ▾ → Загрузить проект»**, чтобы продолжить работу с файлом `.tcat`.

## Горячие клавиши

* `Ctrl + Enter` — зафиксировать перевод (или снять фиксацию) / сохранить термин в глоссарий.
* `Enter` — создать новый абзац с красной строкой внутри сегмента.
* `Esc` — закрыть всплывающие окна, списки счётчиков, справку или окно перехода.

## Форматы файлов

| Расширение | Назначение | Структура |
| :--- | :--- | :--- |
| `.txt` | Исходный текст | Обычный текстовый файл в кодировке UTF-8 (разделение на сегменты по строкам). |
| `.tcat` | Файл проекта | JSON-структура, хранящая сегменты, перевод, заметки, глоссарий и список словарей. |
| `.tdict` | Файл словаря | JSON-словарь формата `{"тибетское_слово": ["описание 1", "описание 2"]}`. |
